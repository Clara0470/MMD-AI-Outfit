# MMD AI Outfit

MMDモデルを衣装処理の対象として登録する、開発初期段階のBlenderアドオンです。

## インストール

1. Blenderで **編集 > プリファレンス > アドオン** を開きます。
2. 右上のドロップダウンから **ディスクからインストール**（または **インストール**）を選びます。
3. `MMD_AI_Outfit.zip` を選び、有効化します。
4. 3Dビューポートで `N` を押し、**MMD AI Outfit** タブを開きます。

## 使い方

1. MMD Toolsで読み込んだモデルのアーマチュア、またはそのモデルに属するメッシュを選択します。
2. **対象モデルとして登録** を押します。
3. 登録されたアーマチュア名がパネルに表示されます。

この段階ではMMD Toolsへの直接依存はありません。通常のBlenderアーマチュアでも動作し、次の段階で体格計測と衣装フィッティングを追加できます。
